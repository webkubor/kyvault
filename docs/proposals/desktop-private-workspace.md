# Ky 桌面侧栏设计

用户打开 Ky 通常为了三件事：找回刚复制过的内容，保存只有自己能看的材料，或挑出一部分想法给别人看。侧栏按这三件事分组。

| 分组 | 栏目 | 点进去做什么 |
| --- | --- | --- |
| 最近使用 | 剪贴板历史 | 找回刚复制的文字或图片。主动点「存入私密收藏」时再选择名称与标签。 |
| 私人空间 | 我的密钥 | 按平台、账号或用途找凭证，点开核对原值，把引用交给工具。 |
| 私人空间 | 私密收藏 | 新建文字、拖入图片，或组成一条图文记录。默认只显示标题，主动展开才显示内容；命名收藏独立于剪贴板清理周期。 |
| 私人空间 | 想法草稿 | 快速记一句想法，可加配图。草稿默认仅自己可见。 |
| 分享与反馈 | 我的分享 | 从草稿勾选段落和图片，预览对方实际会看到的内容。每次分享固定一个版本，修改原稿不自动同步。 |
| 分享与反馈 | 收到的反馈 | 按分享标题汇总回复。点一条能回看对方评论的版本，标为已处理，或加入下一版草稿。 |
| 底部 | 设置 | 集中管理自动记录、保留时间、预览遮挡和语言。 |

第一阶段先做好本地收藏与草稿。用一张图片和一段文字验证保存、重启找回、按标签搜索、主动删除。分享的第一版可先导出选中的图文，由用户自己发送。在线链接和反馈收件箱一起交付；只有服务端能实际执行时才展示有效期、停止访问与反馈状态。已下载的副本无法收回。密钥原值与私密收藏都不自动加入分享。

0.3.0 已实现本地私密收藏、草稿、离线分享和按版本回收反馈。可按标题搜索独立收藏；标签、在线链接和反馈处理状态留在后续设计。
